# Letter grades

**Conditions** · JavaScript · basic

Write `grade(score)` for a score from 0 to 100. Return "A" for 90 and above, "B" for 80–89, "C" for 70–79, "D" for 60–69 and "F" below 60. Scores below 0 or above 100 return "invalid".
