# A chainable account

**this** · JavaScript · advanced

Write `createAccount(owner)` returning an object with `owner`, `balance` (starts at 0), `deposit(n)` and `withdraw(n)`. Both methods must use `this`, change `this.balance` and return `this` so calls can be chained. Withdrawing more than the balance throws an Error with the message "Insufficient funds".

Edit `solution.js`, then commit and push. Your tests run automatically.
