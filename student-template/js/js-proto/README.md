# Shapes with prototypes

**Prototypes** · JavaScript · advanced

`Shape` is given. Write a `Circle(r)` constructor that inherits from `Shape` through the prototype chain (call `Shape` with the name "circle"). Put an `area()` method on `Circle.prototype` that returns π·r². Do not copy `describe` onto Circle.

Edit `solution.js`, then commit and push. Your tests run automatically.
