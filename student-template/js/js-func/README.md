# Greet in three languages

**Functions** · JavaScript · basic

Write `greet(name, lang)` where `lang` defaults to "en". Return "Hello, NAME!" for "en", "ሰላም, NAME!" for "am" and "Akkam, NAME!" for "om" (Afaan Oromo). Any other language falls back to English.

Edit `solution.js`, then commit and push. Your tests run automatically.
